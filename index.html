贴花说明

  1. v4 可贴花面：左右侧视全部白车上身空白（含前柱、主门板、屏周残留、后舱立面）。车头白面浪尖可随侧视白身延伸，无单独前视。
  2. 不可贴花：灰填充黑下底盘、右侧显示屏+安装缝、红银警示贴条（仅后缘，车头无）、门把手、充电口、传感器、轮拱、顶部设备箱。
  3. 斜切在车头（≈6°/内收120 mm）；后缘垂直 + L 开缺（深≈690 mm，台面高≈1260 mm，据紫线实测）；设备箱嵌于凹台内。屏幕/贴条为照片估测，现场复核为准。
  4. 方案 v4 采用重叠有机绿浪（森→中→嫩 + 白丝带）、浪内城景/树/水与叶饰，上层品牌横排；右侧以多矩形 clipPath 绕开屏缝；无软圆角「卡片」、无 v2 斜切雪佛龙。
