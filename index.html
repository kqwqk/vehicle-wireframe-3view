贴花说明

  1. v3 权威可贴花面仅为标注紫区三处：左侧主门板大画布、左后舱门立面、右后舱门立面。其余白身（含右侧前柱/中缝/屏下）及车头均不贴花。
  2. 不可贴花：灰填充黑下底盘、右侧显示屏+安装缝、红银警示贴条（仅后缘，车头无）、门把手、充电口、传感器、轮拱。
  3. 斜切在车头（≈6°/内收120 mm）；后缘垂直 + L 开缺（深≈690 mm，台面高≈1260 mm，据紫线实测）；设备箱嵌于凹台内。屏幕/贴条为照片估测，现场复核为准。
  4. 方案 v3 采用重叠有机绿浪（森→中→嫩 + 白丝带）、浪内城景/树/水与叶饰，上层品牌横排；以 SVG clipPath 精确裁切至三区；无软圆角「卡片」、无 v2 斜切雪佛龙。
