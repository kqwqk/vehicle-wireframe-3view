无人车左右侧视线框 — README
========================

比例 / 单位
  SVG 用户单位 = 1 mm（比例 1:1）
  权威外形尺寸：长 L=3000 mm，高 H=1700 mm，宽 W=1100 mm
  双色分割（据照片估测）：白上车身 1140 mm（~67%），黑下底盘 560 mm（~33%）
  视图：仅左侧视 + 右侧视（无前视、无俯视）

布局
  上：左侧视（车头朝右，与左侧照片一致）— 实心主门板，大可贴花区
  下：右侧视（车头朝左，与右侧照片一致）— 显示屏+安装缝（不可贴花）
  同比例、车长左右对齐

车头斜切 + 后部 L 形开缺（后缘垂直）（据用户紫色标注 + 侧照片）
  斜切在车头（白车身，不含灰底盘）：自底前角向上/向内 ≈6.0°（相对竖直），全白车身高内收 ≈120 mm
    （车顶前缘鼻距 ≈120 mm；白身底前缘鼻距 = 0）。灰底盘前/后缘仍竖直。后缘不斜切。
  开缺深（沿车长，自车尾向前）≈ 690 mm（紫线实测）
  台面高（自地面至水平凹台）≈ 1260 mm（紫线实测；下陷比旧稿更浅）
  主车顶至台面垂直落差 ≈ 440 mm
  后缘垂直（L 开缺竖壁 + 台面外端竖壁均垂直）
  无人机机场设备箱嵌于凹台内：约 340×530 mm（侧视），顶面近乎齐主车顶（低于约 30 mm），后端止于垂直后缘内侧
  切勿将设备画成坐在完整高度后顶之上

右侧显示屏（据右侧照片估测，仅右侧视）
  外框安装缝 ≈ 1280 × 820 mm（距车头约 820–2100 mm，顶边距车顶约 90 mm）
  缝/边框带宽 ≈ 55 mm（底边约 75 mm 含把手）
  内屏填色 #9a9a9a；缝/边框填色 #c8c8c8 — 均为不可贴花
  底部中央保留把手/锁扣
  可贴花区虚线框已缩至屏幕周围残留白身（前门柱、屏前/屏后白条、屏下白边）及后舱门

左侧视
  未见对等显示屏（参考照片无左侧大屏），保持实心主门板 + 大可贴花区，不臆造屏幕

警示贴条（左右侧均有）
  红(#c62828)+银灰(#d0d0d0)交替短段；条带宽 ≈ 50 mm（据侧/后照片测估，约车宽 4–5%）
  贴边短段（贴齐紫色外轮廓）：车头斜切角（顶边横 + 斜边平行四边形 + 底前短横）；
    L 开缺处（开缺前顶边横、竖壁竖、台面顶边横、后缘竖）；后白身下角短横
  属不可贴花；可贴花区虚线已避开贴条

贴花 / 覆膜建议表面
  最佳：侧视残留白身「可贴花区」虚线框（右侧已避开屏幕）；左侧主门板虚线框
  次佳：后舱门虚线框（台面以下）
  禁止：灰填充黑下底盘、右侧显示屏+安装缝、红银警示贴条、轮拱、充电门、门把手、传感器

已知近似 / 估测（非权威实测）
  - 轮径约 Ø480 mm、轴距约 1760 mm（轮心约距车头 620 / 2380）
  - 前门柱宽约 380 mm；主侧门至开缺竖壁距车头 ≈2310；后侧小舱门在台面以下
  - 右侧显示屏外框约 1330×920 mm（估测）；缝带宽约 55/75 mm
  - 凹台内：无人机机场箱 + 小型风速仪
  - 警示贴条宽约 50 mm、充电门位置据照片估测
  - 车身底前圆角半径约 R40 mm；L 开缺为直角；车头白身上缘相对底前角内收约 120 mm（≈6°）；后缘垂直

线框约定
  纯线框黑描边白底；黑下底盘以 #c8c8c8 实心填充标示非贴花；右侧屏 #9a9a9a / 缝 #c8c8c8；警示贴条红银交替；车轮浅灰放射线辅助
