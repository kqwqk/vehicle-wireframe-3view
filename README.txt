无人车三视图线框 — README
========================

比例 / 单位
  SVG 用户单位 = 1 mm（比例 1:1）
  权威外形尺寸：长 L=3000 mm，高 H=1700 mm，宽 W=1100 mm
  双色分割（据照片估测）：白上车身 1140 mm（~67%），黑下底盘 560 mm（~33%）

文件列表
  three-view.svg   — 工程线框三视图（前视 / 侧视 / 俯视），可导入 Illustrator / Figma / CorelDRAW
  three-view.png   — 高分辨率预览（4920×3540 px）
  generate_three_view.py — 生成脚本（可改参数后重跑）
  README.txt       — 本说明
  refs/            — 参考照片副本（非交付必需）

贴花 / 覆膜建议表面
  最佳：侧视大面积主门板（已标「可贴花区」虚线框）
  次佳：前视白车身主立面（Z 标周边「可贴花区」）
  慎用：黑底盘、轮拱、充电门、反光条、传感器遮阳罩、车牌区、门把手
  俯视仅作屋顶设备避让参考，一般不做大面积贴花

已知近似 / 估测（非权威实测）
  - 轮径约 Ø480 mm、轴距约 1760 mm（轮心约 x=620 / 2380）
  - 前门柱宽约 380 mm；主侧门至 x≈2320；后侧小舱门至车尾
  - 屋顶：前 LiDAR、传感器/风速仪桅杆、天线；中后 Houghton AC；尾部设备箱
  - 前脸：顶近传感器遮阳罩、两圆形相机舱、居中圆形 Z 标、黑杠四矩形 LED、绿牌 测 C·L90300
  - 反光条、充电门、LED 条位置据照片估测
  - 车身圆角半径约 R45 mm

布局说明
  经典工程排版：前视在左，侧视在右（共用地平线），俯视在侧视正上方（与侧视长度对齐）
  纯线框黑描边白底；车轮轮胎带浅灰放射线辅助，无写实阴影

配套静态站
  /workspace/vehicle-wireframe-web/  — 可直接拖到 Vercel 的静态站点（见其 index.html）
