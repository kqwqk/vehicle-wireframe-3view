无人车左右侧视线框 — README
========================

比例 / 单位
  SVG 用户单位 = 1 mm（比例 1:1）
  权威外形尺寸：长 L=3000 mm，高 H=1700 mm，宽 W=1100 mm
  双色分割（据照片估测）：白上车身 1140 mm（~67%），黑下底盘 560 mm（~33%）
  视图：仅左侧视 + 右侧视（无前视、无俯视）

布局
  上：左侧视（车头朝右，与左侧照片一致）
  下：右侧视（车头朝左，与右侧照片一致）
  同比例、车长左右对齐

后部 L 形开缺（据侧/后照片估测）
  开缺深（沿车长，自车尾向前）≈ 650 mm（估测）
  台面高（自地面至水平凹台）≈ 1140 mm（估测）
  主车顶至台面垂直落差 ≈ 560 mm
  无人机机场设备箱嵌于凹台内：约 600×420 mm（侧视），顶面低于主车顶约 140 mm，后端近乎与车尾齐平
  切勿将设备画成坐在完整高度后顶之上

文件列表
  three-view.svg   — 工程线框（左侧视 / 右侧视）
  three-view.png   — 高分辨率预览
  index.html / styles.css / vercel.json — 静态站
  README.txt       — 本说明

贴花 / 覆膜建议表面
  最佳：侧视大面积主门板（已标「可贴花区」虚线框）
  次佳：后舱门虚线框（台面以下）
  禁止/慎用：灰填充黑下底盘、轮拱、充电门、反光条、传感器、门把手

已知近似 / 估测（非权威实测）
  - 轮径约 Ø480 mm、轴距约 1760 mm（轮心约距车头 620 / 2380）
  - 前门柱宽约 380 mm；主侧门至开缺竖壁距车头 ≈2350；后侧小舱门在台面以下
  - 屋顶：前 LiDAR、传感器/风速仪桅杆、天线；中后 Houghton AC（均在未开缺主顶）
  - 凹台内：无人机机场箱 + 小型风速仪
  - 反光条、充电门位置据照片估测
  - 车身前圆角半径约 R40 mm；L 开缺为直角

线框约定
  纯线框黑描边白底；黑下底盘以 #c8c8c8 实心填充标示非贴花；车轮浅灰放射线辅助

源码 / 镜像
  生成脚本与镜像副本：/workspace/vehicle-wireframe/
  本目录为可直接拖到 Vercel 的静态站点
